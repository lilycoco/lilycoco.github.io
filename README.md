# lilycoco.github.io

This repository contains the source for **lilycoco**'s personal site. The project is built with **Next.js** and **TypeScript** and styled using **Tailwind CSS**. A small Express server is used to run the Next.js application.

## Development

1. Install dependencies with `npm install`.
2. Start the development server:

   ```bash
   npm run dev
   ```

   The site will be available at [http://localhost:3000](http://localhost:3000).

## Production build

To create a static production build run:

```bash
npm run build
```

The server can then be started with:

```bash
npm start
```

## Linting

Lint checks can be executed with:

```bash
npm run eslint
```
